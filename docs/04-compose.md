# 从素材到书稿

[返回目录](../README.md)

## 写“控制变量”这一章

在书稿项目里说明读者、前后章节、篇幅和学习目标。Codex 检索四个子库，给出带来源的选材单：哪些教材讲得细、哪份数据适合演示、哪些图形可用、旧讲义哪些部分值得保留。

先确定讲解顺序，再生成正文。每个拟采用素材标明版本、改编内容和缺口；没有找到的资源列为缺口，不用生成的内容冒充已存在的资料。

| 环节 | 交付物 | 完成标准 |
|---|---|---|
| 检索 | 候选材料表 | 有来源、位置、适用理由和验证状态 |
| 设计 | 章节大纲与选材单 | 目标清晰、前置知识衔接自然 |
| 组装 | 正文、图形、代码与引用 | 变量定义一致、资产可定位 |
| 核查 | 章节验收记录 | 数值、公式、叙述、链接和预览已检查 |
| 固定 | 书稿内的资产副本与来源清单 | 脱离本机素材库路径也能构建 |
| 回流 | 素材修订提案 | 区分通用改进与本章特有改写 |

网页发布必须使用书稿内部可部署的文件和相对链接，不能让读者的浏览器读取你的 `D:` 盘。复制到书稿的资产要记录上游 ID、版本、数据指纹和生成参数；上游更新后由书稿明确选择是否升级。

## 工资案例的教学顺序

1. 熟悉的二维工资—经验散点图，按教育组着色。
2. 按实际教育年限展开第三个维度，保留原有工资与经验坐标。
3. 加拟合平面、拟合点和沿工资轴的残差线。
4. 对比固定教育时的经验斜率与忽略教育的混合斜率。
5. 教育组固定效应、组均值与组内去均值。
6. 虚拟变量和交乘项：相同斜率与不同斜率。
7. 经验平方项：边际效应随经验变化。
8. 两个连续解释变量的交乘：展示不同方向的斜率变化。

前期教育取 6、9、12、16 年；连续交乘阶段再引入连续教育版本，并明确说明数据版本切换。有限的四个教育组可以画出平面，但组间区域代表模型插值，不能误当成实际观测支持。

负相关与系数反转是该教学样本的设定，不能推广成所有劳动市场的事实。教育组固定效应去掉组间水平差异；共同组内斜率依赖模型设定。加入固定效应也不自动消除所有内生性，更不自动获得因果解释。

后续可沿着“组内比较”延伸到面板固定效应，再讲异质斜率、双重差分；沿着“模型设定”延伸到非线性与函数形式。工具变量和断点回归应另补识别假设与数据结构，不为沿用工资图而勉强套入。
