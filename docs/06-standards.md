## 已确认的内容

| 方面 | 规则 |
|---|---|
| 变量 | 使用 `wage`、`exper`、`edu` 和大写 `D`；原始论文变量保留原名，派生层给映射 |
| 教学连续性 | 工资案例贯穿；前期经验连续、教育取 6、9、12、16，连续交乘另说明扩展 |
| 拟合点 | 很小的红色实心圆点，避免空心菱形的旋转错觉 |
| 观测与残差 | 观测允许偏离平面；拟合值在平面上；残差线沿工资轴并设开关 |
| 散点 | 减少遮挡、适当缩小、颜色鲜亮且不透明；曲面可透明 |
| 布局 | 子图高宽比约 1.0–1.2；图例放图内下方空白或预留区域，避免压住数据与标注 |
| 数学 | 以 LaTeX 源表达，最终必须检查网页与印刷渲染；长公式分行 |
| 可复现 | 固定并保存数据、生成机制、随机方法与环境、参数、代码和图形状态 |
| 使用 | 书稿独立；素材单元可组合；入库记录来源与已验证范围 |

例如模型源可写为：

```latex
\mathrm{wage}_i=\beta_0+\beta_1\mathrm{exper}_i
 +\beta_2\mathrm{edu}_i+u_i
```

正式网页选择可靠的数学渲染方案，检查平方项、交乘项、均值和拟合值。Markdown 源码可读不代表 Pages 已经正确渲染数学公式。

## 推荐默认值，尚不是全库最终标准

- 教育四组用蓝、橙、紫、绿，具体色值与字号保存为可调整主题；12 年与 16 年明显区分。
- 素材用稳定语义 ID，版本独立管理。文件名示例：`wage-within-p3_261022-a7c29e.png`，包含单元、视图、日期和短指纹。
- 文档使用稳定语义文件名，修订交给 Git；对外发布包与不可变截图带版本或指纹。短指纹要检查冲突，不能只凭长度假定不会重名。
- `AGENTS.md` 做入口和规则导航；详细规范放 `_system/`，避免复制大量重复条款。
- 后续考虑 `tb-capture`、`tb-curate`、`tb-compose` 三个技能。先稳定流程再实现，技能不赋予额外权限。技能机制可参考 [OpenAI 文档](https://learn.chatgpt.com/docs/build-skills)。

## 可复现与印刷的验收要求

随机种子只是其中一项。还需要随机算法、环境版本、样本构造、误差处理和生成数据文件的指纹。一个固定教学样本用于贯穿讲解；重复抽样的 Monte Carlo 实验单独设计，不把一次随机演示称为完整模拟研究。

精心构造的样本可能让组内斜率恰好等于目标值，应披露构造方法。普通随机样本则保留抽样波动，两者服务不同教学目的。

静态截图记录相机位置、坐标范围、画幅、图层开关与数据版本；同一角度不适合所有机制。纸质版至少评估一个总体斜视图及一个辅助视图或二维切片，实际检查缩放后的字号、遮挡与灰度辨识。

教学状态、数据和模型分别保存。改变参数时说明是在改变真实机制、重估模型，还是仅移动展示图层，不能悄悄改变原有观测数据。
