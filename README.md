# AI 协作教研工作流

**从想法到素材库与书稿 · 讨论稿 v0.1 · 2026-10-22**

这份手册面向持续写讲义、教材和在线书的教师。目标是把临时想法、教材阅读、论文复现和既有讲义连接起来，让下一次写作可以检索、核查和复用已有积累。

当前交付的是工作方式的草案，尚未创建 teach-bank 素材库或安装 skills；本手册提供独立的 GitHub Pages 阅读版。此前生成的计量图形包仍属于实验成果，需要按最终规范重新验收。

## 从哪里开始

| 你正在做什么 | 阅读入口 |
|---|---|
| 第一次设置目录、理解三个项目的关系 | [本地布局与协作边界](docs/01-setup.md) |
| 有了一个新想法，希望逐步沉淀 | [从想法到入库](docs/02-capture.md) |
| 整理教材、复现论文、提取旧讲义 | [四个子库及其关联](docs/03-library.md) |

| 换电脑、恢复版本、推送和发布 | [同步、版本与发布](docs/07-maintenance.md) |

日常主线：**提出想法 → 查已有材料 → 讨论与试做 → 核查 → 确认入库 → 书稿选用 → 改进回流。**

你主要决定教学目标、讲解取舍和是否接受结果；Codex 承担检索、整理、实现、检查及记录。涉及首次软件安装、账号授权和发布范围，也需要你的参与。

## 这套系统是什么

可以称作“AI 协作教研知识库”：知识管理、可复现研究和文档版本管理结合的一种工作方式。Wiki 可以作为阅读入口，Git 管理文件历史，skills 封装重复操作，它们分别承担其中的一部分。这里不把某一种产品名称当作整套体系的名称。

先用普通文件和清晰规则实现闭环；全文检索、语义检索或数据库应在真实使用出现瓶颈后再增加。

## 草案的维护方式

本仓库只存工作手册、提示词和流程说明。素材的正式规范将由 teach-bank 的 `_system/` 维护；手册解释如何使用并指向规范，避免两边分别修改同一条规则。

建议按“设置 → 一个想法入库 → 一本书选用 → 回流修订”的顺序试运行一次，再决定是否制作自动化技能。

本稿已公开分享，暂未授予开源许可；后续另行确定原创文档和代码的授权方式。文献、教材和第三方数据的许可需要分别记录，不能随手册统一授权。
